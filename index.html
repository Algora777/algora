08 / FAQ

Before you connect a broker.

Is algo trading legal for retail traders in India?

Yes. Under SEBI's retail algo framework (circular of 4 February 2025, applicable to all brokers from 1 April 2026), retail traders can automate through their SEBI-registered broker's API. Orders carry an exchange-issued algo tag and API access runs from a whitelisted static IP.

Does Algora hold my money or place real orders today?

No. Algora never holds funds. Bots currently run in paper mode only, so no real orders are sent. Live trading will route through your own broker account.

Where are my API keys stored?

Never on this page. Real API keys belong in your bot's own server environment. The web app only keeps account labels, bots and settings in your browser.

What data does the backtester use?

Your own candle CSV (datetime, open, high, low, close). It runs entirely in your browser and nothing is uploaded.

Which brokers are supported?

Zerodha, Upstox, Angel One, Dhan, Fyers, Groww, Kotak Securities, 5paisa, Alice Blue, Shoonya, Motilal Oswal and ICICI Direct.
